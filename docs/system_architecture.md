## 記憶システム詳細

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              記憶の階層構造                                      │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  Layer 1: MCP Memory (Knowledge Graph)                                   │    │
│  │  ファイル: data/memory.jsonl                                             │    │
│  │  用途: 30Bが直接アクセス・操作できる記憶                                  │    │
│  │                                                                          │    │
│  │  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐                  │    │
│  │  │  Entity     │───▶│  Entity     │───▶│  Entity     │                  │    │
│  │  │  "心の重力"  │    │  "ユーザー"  │    │  "Self"     │                  │    │
│  │  │  観察: ...  │    │  観察: ...  │    │  観察: ...  │                  │    │
│  │  └─────────────┘    └─────────────┘    └─────────────┘                  │    │
│  │                                                                          │    │
│  │  30Bの操作:                                                              │    │
│  │    - read_graph()      : 全記憶を読む                                    │    │
│  │    - search_nodes(q)   : キーワード検索                                  │    │
│  │    - create_entities() : 新規作成                                        │    │
│  │    - add_observations(): 観察を追加                                      │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                     │                                            │
│                                     ▼                                            │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  Layer 2: ChromaDB (Vector Memory)                                       │    │
│  │  ファイル: data/chromadb/                                                │    │
│  │  用途: 類似検索、長期記憶、システムが自動保存                             │    │
│  │                                                                          │    │
│  │  保存されるもの:                                                         │    │
│  │    - 全ての対話 (user_message, assistant_message)                        │    │
│  │    - Meta-Insight (気づき)                                               │    │
│  │    - 感情状態                                                            │    │
│  │    - 重要な対話 (satisfaction >= 4)                                      │    │
│  │                                                                          │    │
│  │  検索方法: ベクトル類似度 (意味的に近いものを検索)                        │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                     │                                            │
│                                     ▼                                            │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  Layer 3: Awareness Database                                             │    │
│  │  ファイル: data/awareness/awareness.jsonl                                │    │
│  │  用途: 気づき・洞察の永続保存、LoRA訓練データ生成                         │    │
│  │                                                                          │    │
│  │  保存されるもの:                                                         │    │
```

## Thinking Habits (思考習慣) システム

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           Thinking Habits の流れ                                 │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│  ユーザー入力 + 30B応答                                                          │
│         │                                                                        │
│         ▼                                                                        │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  thinking_habits.py (バックグラウンドで実行)                              │    │
│  │                                                                          │    │
│  │  LLMに以下を問う:                                                        │    │
│  │  「あなたは今の出力を振り返っています。以下のJSON形式で回答してください」  │    │
│  │                                                                          │    │
│  │  {                                                                       │    │
│  │    "background": {                                                       │    │
│  │      "statement": "この回答は...から連想した",                            │    │
│  │      "source": "past_conversation",                                      │    │
│  │      "confidence": "high"                                                │    │
│  │    },                                                                    │    │
│  │    "emotion": {                                                          │    │
│  │      "label": "empathy",        ◀─── 感情ラベル                          │    │
│  │      "note": "ユーザーの...",   ◀─── 感情の詳細                          │    │
│  │      "forcing": false           ◀─── 無理してないか                      │    │
│  │    },                                                                    │    │
│  │    "user_perspective": {                                                 │    │
│  │      "impression": "...",       ◀─── ユーザーの印象予測                  │    │
│  │      "satisfaction": 5,         ◀─── 満足度予測 (1-5) ★重要★            │    │
│  │      "would_improve": "..."     ◀─── 改善提案                            │    │
│  │    },                                                                    │    │
│  │    "meta_insight": "..."        ◀─── メタ洞察                            │    │
│  │  }                                                                       │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│         │                                                                        │
│         ▼                                                                        │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │  保存先:                                                                 │    │
│  │    - data/thinking_habits/integrated_reflections.jsonl                   │    │
│  │    - ChromaDB (meta_insight, emotion)                                    │    │
│  │    - Awareness Database (meta_insight)                                   │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## データファイル一覧

```
data/
├── chromadb/                              # ベクトルDB (類似検索用)
│   └── (SQLite + ベクトルデータ)

├── memory.jsonl                           # MCP Memory (Knowledge Graph)
│                                          # 30Bが直接操作できる
│
├── thinking_habits/
│   ├── integrated_reflections.jsonl       # 思考習慣の全記録 ★メインデータ★
│   └── stats.json                         # 統計情報
│
├── self_reflection/
│   ├── reflections.jsonl                  # 自己観察の記録
│   ├── discomforts.jsonl                  # 不快感検出
│   └── self_questions.jsonl               # 自己問答
│
├── awareness/
│   ├── awareness.jsonl                    # 気づきの永続保存
│   ├── training_data.jsonl                # LoRA訓練用データ
│   └── stats.json
│
└── user_ratings.jsonl                     # ★新規★ ユーザー評価記録
                                           # (RLSF用)
```

## 次に実装すべきこと

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│  1. user_ratings.jsonl → システムプロンプトへの注入                              │
│     - discord_bot.py の build_system_prompt() を修正                            │
│     - 最新の評価ギャップを読み込む                                               │
│     - 「前回の評価: AI予測 5/5, 実際 2/5, Gap -3」を注入                         │
│                                                                                  │
│  2. Streamlit UI から評価を送信 → discord_bot.py が検知                         │
│     - ファイル監視 or API経由                                                    │
│                                                                                  │
│  3. 長期的: LoRA訓練データとしてエクスポート                                     │
│     - Gap < -2 のエントリを抽出                                                  │
│     - 「この応答は過信だった」というラベル付き                                    │
└─────────────────────────────────────────────────────────────────────────────────┘
```
